# Auralith · versiones para Windows

[Descargar el cliente de Auralith](https://github.com/scanalesespinoza/auralith-releases/releases/latest)

En Assets elige **Auralith-Launcher-1.0.0-Windows-x64.zip**. Extrae la carpeta
completa y abre **AuralithLauncher.exe**. No hace falta una cuenta de GitHub.

El cliente busca el último release publicado, descarga los archivos modificados,
verifica su firma e integridad y activa la nueva versión. Permite reparar y
restaurar la versión anterior. Puedes jugar sin Internet una vez instalado.
Las partidas se conservan aparte y la actualización espera si el juego está abierto.

El juego es una demo en desarrollo. La Compañía permite aventuras cooperativas
de hasta cuatro jugadores por IP; Internet requiere una ruta accesible o VPN.

Este repositorio distribuye versiones e instrucciones. El desarrollo del juego
se mantiene separado. Los archivos sueltos EXE/PCK y manifiestos de los releases
son utilizados por el actualizador; para empezar utiliza el ZIP del cliente.

El cliente requiere Windows x64 y .NET Framework 4.8. Su ejecutable todavía no
posee certificado comercial de editor de Windows. Las actualizaciones del juego
sí se verifican mediante manifiesto RSA-SHA256 y hash de cada archivo.

No desactives las protecciones del sistema si una política impide ejecutarlo.
También puedes descargar el ZIP del juego de este mismo release.
